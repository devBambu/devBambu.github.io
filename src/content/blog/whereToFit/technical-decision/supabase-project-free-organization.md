# [의사결정기록] WhereToFit Supabase 프로젝트의 무료 조직 분리

### 📝 Supabase 프로젝트의 무료 조직 분리

#### 🗓️ 2026-10-11 (일) ~ 2026-10-12 (월)

타 프로젝트(잎로그)의 file Storage 용량 부족으로 인한 Supabase 유료 결제를 검토하였다.

유료 플랜 결제 시, 해당 조직에 프로젝트가 2개 이상일 경우 결제금이 추가된다는 사실을 확인하였다.



**운동갈지도(WhereToFit)** 는 Supabase에서 시설·프로그램과 추천 규칙을 조회하고 Edge Function을 호출한다.

사용자 기록은 CoreData와 CloudKit 기반으로 관리하고 있다.


## 의견

### 1. 잎로그(Leaflog)의 file Storage 용량 90% 소진으로 인한 관리 방안 논의

1) 무료 플랜 유지 + 저장 중인 이미지 최적화 및 파일 정리

   - 이미 원본 이미지를 압축하여 저장하고 있으므로 보관중인 데이터 재 변환 시 이미지 손상 우려
   - 기존 파일 정리 시 현재 운영중인 서비스 지장 우려

2) 외부 스토리지 분리

   - 보관중인 데이터 유실 및 손상 우려
   - 기존 이미지 저장 관련 코드 리팩토링 필요
   - 분리 후에도 해당 스토리지 무료 용량 초과 시 유료 결제에 대한 문제 재발생 가능성

3) 유료 플랜 업그레이드

   - 기존 코드 유지 가능, 보관중인 데이터 손상 우려 없음
   - 유료 플랜 사용 비용 발생

⇒ **3) 유료 플랜 업그레이드** 선택


### 2. Supabase 조직 내 프로젝트 2개 이상 존재 시 유료 플랜 업그레이드에 추가 비용 발생

잎로그 프로젝트를 위한 유료 플랜 업그레이드이므로 조직 내 '잎로그' 프로젝트는 유지하고 '운동갈지도' 프로젝트의 관리 방향에 관하여 논의함.

1) 유료 Supabase 프로젝트(잎로그)에 병합하여 함께 두기

    - 운동갈지도의 데이터를 잎로그 프로젝트로 이전하여 하나의 유료 플랜 프로젝트에서 관리 → 추가 비용 미발생
  - 서로 다른 앱의 데이터를 한곳에서 관리 시 오류 발생 가능성↑

2) 외부 스토리지 분리

    - Supabase가 아닌 별도 무료 원격 저장공간을 제공하는 DB로의 분리
    - 기존 코드 리팩토링 필요

3) 별도 무료 조직 생성 후 프로젝트 이전

    - 기존 조직(jooslin)이 아닌 별도 조직을 생성하여 프로젝트 이전
    - 개인 계정 사용 시 무료 플랜 최대 조직 슬롯이 소비됨 (무료 플랜 계정은 최대 2개의 조직 생성 가능)


## 결과

기존 잎로그와 운동갈지도가 함께 존재하던 Supabase 조직 `jooslin`의 프로젝트 수를 1개로 줄이고, 유료 플랜을 결제하였다.

운동갈지도 프로젝트는 개인 계정에 신규 조직을 생성하여 이전하였다.

기존 `jooslin` 조직에서 존재하던 운동갈지도의 프로젝트 URL이나 Key값은 이전 후에도 동일한 것으로 확인하여 프로젝트 이전 외 추가적인 작업 사항은 없었다.



## 선정 이유

### 1. 유료 플랜 업그레이드

- 커뮤니티 기능 확장 진행중으로, 추후 이미지 저장 수요가 더 늘어날 것으로 예상되어 무료 플랜 유지는 부적절하다고 판단
- 외부 스토리지 분리 시 데이터 손실 우려

⇒ 리팩토링 공수가 적고 데이터 손실이 적은 **유료 플랜 업그레이드** 방안을 선택하였다.

추가적으로, 장기적인 이미지 저장 용량 절감을 위해 이미지 저장 포맷을 기존 `jpeg` → `avif / webp`로의 전환을 고려하기로 하였다.

### 2. 별도 무료 조직 생성 후 운동갈지도 프로젝트 이전

운동갈지도는 공모전 출품을 위한 프로젝트로, 추후 개발을 계속 이어갈지에 대한 사항이 불분명하다.

이에 따라 외부 데이터베이스로 이전하여 관련 기능에 대한 리팩토링을 하는 것은 효용이 떨어진다고 판단하였다.

또한 잎로그는 현재 지속적으로 사용자가 존재하며 운영중인 서비스이므로, 잎로그와 운동갈지도의 프로젝트를 합쳐서 관리하는 것은 현재 운영중인 잎로그 서비스에 지대한 영향을 끼칠 수 있다고 판단하여 해당 방안은 고려하지 않았다.

개인 계정의 조직은 2개까지 생성 가능하므로, 기존 사용중이던 조직이 없어 슬롯 하나를 운동갈지도에 할당하여 새로운 조직으로 운동갈지도 프로젝트를 이전하였다.
